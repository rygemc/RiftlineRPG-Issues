# RiftlineRPG Issue Tracker

This repository is used to track bugs and technical issues with RiftlineRPG.

## Found a bug?

Open a new issue using the Bug Report form and provide as much information as possible.

Please include:
- RiftlineRPG version
- Singleplayer or multiplayer
- Steps to reproduce the issue
- Any modifications made to the pack
- `latest.log` or crash report when relevant

## Need Help?

If you have a question, need installation help, or aren't sure whether something is a bug, please use the RiftlineRPG Discord server.

[Join the RiftlineRPG Discord](https://discord.gg/W9ATyBadY5)

## Suggestions

Suggestions and feature ideas are handled through the RiftlineRPG Discord community.

## Modified Installations

RiftlineRPG is tested using the official modpack configuration. Issues caused by added, removed, or manually updated mods may not be supported.
